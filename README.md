# Midrift Built Strong

You are building a premium B2B website for MIDRIFT CONCRETE SOLUTIONS LTD, a Kenyan precast concrete manufacturing and construction-solutions company.



IMPORTANT:

Do not treat this as a generic construction-company website.

Do not make it look like a hardware shop.

Do not use a generic template aesthetic.



The website must position Midrift as a serious, modern, trustworthy manufacturer and supplier capable of serving individual builders, contractors, developers, hardware stores, distributors, architects, quantity surveyors, infrastructure companies and government-related projects.



CORE BRAND POSITIONING:



MIDRIFT CONCRETE SOLUTIONS LTD



Core message:

QUALITY PRECAST CONCRETE. BUILT FOR STRENGTH. DESIGNED FOR PERFORMANCE.



The broader positioning should communicate:



Products + Manufacturing + Technical Knowledge + Project Supply + Custom Solutions + Logistics.



The website must function as:

1. Premium corporate website

2. Product catalogue

3. Technical information platform

4. Project portfolio

5. Lead-generation system

6. Quote-request system

7. Social-media gateway

8. SEO platform

9. Foundation for a future B2B ordering platform



DESIGN DIRECTION:



Create a modern industrial corporate aesthetic.



Visual character:

- Premium

- Strong

- Architectural

- Minimal

- Elegant

- Technical

- Confident

- Modern

- Trustworthy



Avoid:

- Generic construction templates

- Cheap-looking layouts

- Excessive gradients

- Excessive rounded cards

- Excessive animations

- Overly colourful designs

- Stock-photo-heavy layouts

- Clutter

- Tiny typography

- Huge blocks of text

- Fake statistics

- Fake certifications

- Fake customer reviews



COLOUR SYSTEM:



Use a restrained industrial palette:

- Deep charcoal

- Concrete grey

- White/off-white

- Black

- One strong Midrift accent colour



The exact accent colour should be easy to modify globally through CSS variables/design tokens.



Use the accent colour selectively for:

- Primary CTAs

- Links

- Active states

- Important highlights

- Interactive elements



Do not cover the entire interface in the accent colour.



TYPOGRAPHY:



Use a modern premium sans-serif system.



Headings:

- Bold

- Architectural

- Strong

- Large

- Tight but readable



Body:

- Clean

- Highly readable

- Professional

- Short paragraphs



Use a clear type scale and consistent hierarchy.



LAYOUT:



Use:

- Generous whitespace

- Strong visual hierarchy

- Large photography

- Asymmetric layouts where appropriate

- Clean grids

- Full-width visual sections

- Strong section transitions

- Consistent spacing

- Excellent mobile layouts



Do not make every section a card grid.



PHOTOGRAPHY:



The company has real Midrift photographs that will be provided separately.



When image assets are supplied:

- Use the real Midrift images instead of generic stock photography.

- Preserve aspect ratios.

- Never distort products.

- Use high-quality crops.

- Create reusable image-gallery components.

- Allow different images to be assigned to products, projects, manufacturing sections and hero sections.

- Optimize images for web performance.



Do not invent photographs.
